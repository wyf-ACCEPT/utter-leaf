# UtterLeaf 产品需求

## 用户目标

Jason Wang / PlanD 希望做一个对标 Typeless 的 macOS 语音输入 App。已认可当前豆包转写加 DeepSeek Flash 整理的大部分效果；现在进入独立项目阶段，不继续扩展原 Reverse Anything 会话。

## 核心流程

1. 全局快捷键开始和结束录音；按住说话或点击切换两种交互可先择一实现，并保留后续扩展空间。
2. 录音状态清晰可见，支持取消，正确处理麦克风拒绝、无输入/静音、设备断开、网络失败和超时。
3. 选择 ASR 管线，拿到完整最终文字。
4. 选择整理步骤；默认先接 DeepSeek Flash，可跳过整理以查看原始转写。
5. 将正文输入回原应用；确保取消、失败和焦点变化时不会误输入或自动发送消息。
6. 保存本地使用记录。录音、原始转写、最终文字的保留范围和时长应有清楚开关。

MVP 建议是菜单栏常驻工具、一个录音状态浮层和一个设置/历史/用量窗口。具体设计和技术栈由新会话基于本机环境制定，不把这份建议当作已获确认的 UI 稿。

## 模型选择

三条已验证候选都保留，不在立项时决定最终默认值：

| 选项 | 官方资源 ID | 接口 | 说明 |
|---|---|---|---|
| 流式 2.0，结束后返回 | volc.seedasr.sauc.duration | WSS /api/v3/sauc/bigmodel_nostream | 可以后台上传而不逐字显示 |
| 流式 2.0，实时模式 | volc.seedasr.sauc.duration | WSS /api/v3/sauc/bigmodel_async | 可边说边识别，最终稿仍统一整理 |
| 文件标准版 2.0 | volc.seedasr.auc | POST /api/v3/auc/bigmodel/submit + query | 适合已有录音；audio.data 直传是实测接法 |

这些语音接口的域名为 openspeech.bytedance.com。前两条是同一流式模型的两种模式，不能宣传成两个不同模型版本。

整理模型为 DeepSeek 官方 `deepseek-flash`，实验使用非思考模式。保留未来其他文字整理模型的适配接口；当前不要使用公司的 OpenRouter。

## 文字整理

- 忠于原意，去掉填充词、口吃和机械重复，保留有效语气。
- 按语义分段，可将明确的并列任务/方案整理成列表。
- 数字、否定、范围、条件、顺序和例外是重点保真项。
- 保留中英混说；通过独立词表解决专名拼写，不凭空猜测。
- 不回答/执行口述中的问题和命令，不补完未说完的句子。
- 符号词有条件转换：命名中的“杠”→ `-`、斜杠→ `/`、下划线→ `_`、成对口述括号/引号→实际符号。
- 讨论“杠字、括号、引号”的普通语句要保留文字；范围不明确时不擅自加符号。
- 支持 prompt 版本标识、用户编辑、回滚，并在历史条目里记录实际使用的版本。

## 用量与费用页面（用户明确要求）

每次识别任务保留唯一业务 ID；任务下可有 ASR、整理、重试等多个独立调用。避免仅按“成功任务数”估算成本，失败或重试也可能有已发生的费用。

至少展示：

- 按日期和供应商/模型查看调用次数、音频时长、成功/失败次数。
- 整理步骤的输入、输出、缓存 token 等服务端实际返回用量。
- 供应商公布单价与本机实际平均成本分开显示。
- 单次和累计金额；有服务端账单值就标“实际”，仅按单价计算则标“估算”。
- 实际平均每千字：选定范围的成本 ÷ 对应输出字符数 × 1000。原始转写和最终稿分别计数，明确当前展示的是哪一种。
- 实际平均每小时：成本 ÷ 对应音频小时数。ASR 单独和包含整理的端到端成本都可查看。
- 零输出或零时长时显示不可计算，不能显示成免费。
- 保留原始币种和计费单位；人民币换算需记录汇率及时间，不用固定汇率冒充实时汇率。
- 每条记录保存计价版本/生效日期。以后改价格不应覆盖历史估算依据。

字符数、token 数、中文字数是不同指标。初版可统一按 Unicode 字符数计“每千字”，同时标注统计口径；汉字数或英文词数可以另列。按音频时长/token 收费的服务不能直接称为“按输出字数计费”。

## 隐私与凭证

私人音频/文字不使用公司 OpenRouter Key，不接入公司日志平台。云端 ASR/整理仍会把内容传给对应供应商，不能宣称完全离线或“任何第三方都看不到”。

密钥不要进入普通日志或导出文件。音频保留策略、文本历史策略、清除历史和导出范围应对用户可见。额外识别屏幕/应用上下文、自动上传其他文件或云同步不属于当前已确认范围。

## 首轮验收建议

- 从录音到插入文字完整跑通，能在试用中切换三条 ASR 管线。
- 取消、失败、无输入、焦点切换不产生误输入，也不自动发消息。
- v6 符号正反例和原来的数字/指令/断句测试回归。
- 用量记录能逐笔对应 API 回执；界面每千字/小时的结果可用样本手工验算。
- 凭证、录音、文本保留策略和原应用输入权限有明确实现与测试。
