## Fn 绑定更新 · 2026-10-23

用户要求直接绑定 Fn，并表示已退出 Typeless。录音快捷键改为单按并松开 Fn 切换开始/结束，界面、悬浮条、菜单和帮助统一显示 Fn。

旧 Carbon 注册替换为主 run loop 上的 CGSession event tap；只消耗 Fn 本身的 modifier 事件，避免触发系统 Globe 动作，不改系统键盘设置。Fn 与其他键/修饰键组合时不触发录音，普通事件透传；代码不读取、保存或记录按键文字。监听需辅助功能权限，授权变化后自动重试；event tap 超时/失效及休眠/会话停用时重置按键状态。
