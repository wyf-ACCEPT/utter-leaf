# UtterLeaf 自动输入、词汇表与录音交互 · 2026-10-23

## 用户决定

- Fn 结束后整理文字并自动输入原输入框；替代最初的预览确认优先。
- 词汇表放在左侧一级导航。
- 修正语音输入软件语境中的 Typeface → Typeless。
- 波形参考 GitHub 开源方案，采用轻量实现。
- 侧栏/自定义按钮悬停显示手形光标和浅色反馈。
- 修复旧版预览即使已复制仍锁住下一次录音的问题。

## 自动输入

默认路径：捕获原应用与输入框 → Fn 录音 → ASR → 整理 → 验证焦点/光标 → 输入 → 回到待机。成功时不打开主窗口。

自动路径不会激活别的应用。若焦点、输入框或光标已变化，正文保留到可编辑界面。设置保留“先在 App 内预览”作为可选方式。原“确认回填”是手动把预览稿插入原输入框；现更名为“输入到原应用”，用于恢复或预览流程。

Codex / ChatGPT 和浏览器输入框直接使用临时剪贴板与正常键盘路径的 Cmd+V；其他原生输入框尝试 AXSelectedText 后也必须读回正文/光标确认。接口成功但正文与光标均未变时才可退到粘贴；未知写入状态不重试。粘贴后最长约 900ms 读回，未变则保稿并记录 paste_not_applied。绝不按 Return。恢复剪贴板前检查 changeCount 和文本归属，避免覆盖用户的新复制。AX 写入结果不明时不再补发粘贴，避免重复；粘贴无法读回确认时，历史单列 paste_dispatched 而非伪装已确认写入。

复制保留稿会保存后结束预览。新录音也会先按用户的保留策略保存旧稿，不再因为旧预览锁住 Fn。退出时保留未完成预览，避免把已整理稿误标为取消。

## 词汇表

一级入口“词汇表”，支持增改、启用/停用、删除确认、搜索/清除、每次加载 30 条、输入校验和未保存修改确认。预置 Typeless，Typeface 为容易误写的形式；讨论字体词义时保留 typeface。

词条仅用于整理上下文，不在原 ASR 上全局替换。启用条目以结构化 JSON vocabulary 数据传给个人 DeepSeek API；原始稿保留。录音开始时固定本次词表，重试整理读取最新版本。v6 文件保持原文，App 追加固定 vocabulary-v1 规则；调用保存实际 system prompt hash 与词表 hash，任务版本标记 +vocabulary-v1。

关闭整理时词表不生效。UI 明确说明启用的词条会随整理请求传给供应商，词表并非完全不出本机。

## 轻量波形

用户试用后不满意旧条形效果，现参考 MIT [SpeechWaveAnimation](https://github.com/mvolpato/SpeechWaveAnimation) 的正弦/抛物线包络，适配为三个低成本 Canvas 路径。移除 DSWaveformImage 包依赖和锁文件，保留新来源许可证。

复用同一份 RMS，最多保留 128 点；最近 0.4 秒幅度驱动声线，快升慢落。局部 30fps 目标，不增加采音/FFT。只有 recording 阶段创建波形，starting/transcribing/cleaning/inserting 仅显示状态和小进度。Reduce Motion 无相位运动、5Hz 更新。帧率和录音占用仍需实机观察，不以实现频率宣称实际帧率。

## 交互反馈

共享 HandCursor、SidebarItem 和 PrimaryButtonFace：启用的自定义按钮显示 pointing-hand，未选导航有浅色 hover 预览，已选导航保留更强底色。悬停过渡 120ms；Reduce Motion 下即时切换。禁用时重置光标，不出现可点击反馈。

## 验证

- 36 项 XCTest 通过，包括自动输入不弹窗、不激活其他应用、焦点失败保稿、缺失目标、可选预览、过期结果不输入、旧预览可让出新录音、词表数据封装/CRUD/去重校验、音量历史/平滑/静音回落。
- 真实 API 合成检查：v6 口述符号通过；Typeless 软件语境正例通过；字体 typeface 反例通过。回执在 `.local/verification/vocabulary-smoke-r2/`。首版词表正例曾未命中，强化语境规则后复测通过，不把失败隐藏成全通过。
- 原生界面确认：词汇表一级入口、预置项、编辑表单、空词验证；新包启动后录音按钮可用。没有向现有聊天或文档自动写入测试内容。
- 模拟目标验证的是状态逻辑。新版在真实外部应用中的 AX/粘贴兼容性、30fps 实际录音性能和实体鼠标反馈仍应结合用户实机试用判断；不以 mock 或包体大小代替这些验收。
- 没有重跑历史录音研究，没有使用公司 OpenRouter Key。

## 用量额度与快捷取消更新

- CNY 卡片标题统一；金额四位小数。顶部滚动 7 天 / 30 天预算默认 ¥5 / ¥20，可编辑。显示剩余百分比/金额、完整成功听写样本推算的千字额度；未知金额单独提示。不受下方筛选影响，不限制录音，不代表账户余额。
- 每千字/每小时估算及已核对实际统一在页面底部展示，保留供应商对比。日期/供应商/模型/字数口径筛选暂留。
- Fn 后 Esc 复用取消逻辑，停止录音/转写/整理并使旧结果失效；输入已开始后不打断。待机时 Esc 交回原应用。
- 增加可选 targetBundleID / insertionErrorCode 诊断，不记录输入框原文。历史 JSON 向后兼容。
- 46 项测试通过，含空写入不确认、UTF16 光标、实际内容读回、预算滚动窗口/币种隔离/字符去重/未知金额/超额归零。真实输入框验收结果另见当前 handoff，不以这些单测代替实机。

## 费用构成与明细弹窗

用户确认预算要包含豆包 ASR + DeepSeek 整理，已在两项滚动预算下明确说明，并显示已知估算的供应商成本百分比与豆包 : DeepSeek 比值。未知金额不参与占比；无费用时显示暂无数据；DeepSeek 为零时不显示无穷比值。历史外币不混入 CNY 构成。

逐次调用列表从主页面移入 CallHistorySheet。主页面只有“查看明细”入口和当前筛选计数；弹窗 700×550pt，固定标题/关闭按钮/计数，原生 ScrollView + LazyVStack 独立滚动，每次加载 30 条，继承主页面筛选。条目仍可进入回执与账单核对，关闭回执回到明细列表。入口与条目具备手形、悬停/按下反馈。

47 项 XCTest、Release 个人签名构建、DESIGN lint、严格静态检查通过。原生 UI 确认成本占比、主页面移除列表、明细弹窗布局与 30 / 38 计数。发现用户新录音进行中后暂停界面操作，未发 Escape 干扰本次任务。
